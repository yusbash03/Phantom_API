- [x] 29. SignalR real-time with reconnect + polling fallback — _Requirements: 13.1–13.4, 2.7_
  - Verified 2026-11-20: 150 unit tests (2 live skipped) and 126 integration tests (4 new, stable over 3 runs). The new tests cover: anonymous hub connections refused (401); staff getting identifier-only events (type, incidentId, assignmentId, responderId, at) only after commit, so the record is already readable; a failed write (409) publishing nothing; responders hearing only about their own assignments, availability and notifications, with another responder and staff not receiving them. 89 Vitest (7 new) and 40 Playwright tests (4 new). The e2e tests check that the dashboard and recent activity update without a reload or polling; that an assignment appears on the responder's open My assignments page and a decline reverts the coordinator's open incident page; and that "Live updates paused" is shown, with the screen still working, when the hub is unreachable.
  - The server derives events from EF's change tracker (`RealtimeChangeInterceptor`), so no write path can forget to publish. They are published after SaveChanges, or when an explicit transaction commits, and discarded on failure or rollback. Event types: IncidentCreated, IncidentUpdated, IncidentStatusChanged, IncidentResolved, AnalysisCompleted, AssignmentCreated, AssignmentAcknowledged, AssignmentStatusChanged, AssignmentUpdated, ResponderAvailabilityChanged, NotificationCreated.
  - `OperationsHub` (`/hubs/operations`, `[Authorize]`, no client-callable methods) assigns groups from claims and records only: `staff`, `responder:{own linked responder}`, `user:{id}` (notifications to their recipient only). The JWT is accepted from `access_token` only on the hub path; request logs record the path, never the query string. Connections close when the token expires (`CloseOnAuthenticationExpiration`), and the client reconnects with a refreshed token.
  - The client (`@microsoft/signalr` 10.0.11) invalidates TanStack Query keys per event and never patches from the payload. It reconnects forever with jittered backoff (0, 2, 5, 10, 20 s, then 30 s) and invalidates the whole cache after any gap. The top bar shows "Live" or "Live updates paused". While paused, the dashboard polls every 60 s and notifications, My assignments and the map every 30 s; while live they don't poll.
